# Annoncé

Тестовое задание для компании OSMI. Профиль компании с товарами, услугами и агентами на Nuxt 4 + Tailwind CSS.

## 📋 Описание

Проект представляет собой адаптивный веб-интерфейс профиля компании с возможностью просмотра:

- **Товаров и услуг** - каталог с карточками товаров, фильтрацией по категориям
- **Агентов** - список агентов компании с рейтингами и описаниями
- **О компании** - информация о компании, режим работы, местоположение

## 🎯 Основные возможности

- ✅ Адаптивный дизайн (мобильная и десктопная версии)
- ✅ Табы для переключения между разделами
- ✅ Выпадающее меню с категориями товаров
- ✅ Карточки товаров со статусом (активные, продвигаемые, скрытые)
- ✅ Список агентов с рейтингами и верификацией
- ✅ Современный стек: Nuxt 4, Tailwind CSS 4

## 🛠 Технологический стек

- **Nuxt 4** - фреймворк
- **Tailwind CSS 4** - стили
- **ESLint** - линтер

## 📦 Установка

```bash
npm install
```

## 🚀 Разработка

```bash
npm run dev
```

Приложение откроется на `http://localhost:5173`

## 🔨 Сборка

```bash
npm run build
```

Оптимизированная версия будет в папке `dist`

## 👀 Предпросмотр

```bash
npm run preview
```

## 📝 Скрипты

- `npm run dev` - запуск dev-сервера
- `npm run build` - продакшн-сборка
- `npm run preview` - предпросмотр собранного проекта
- `npm run lint` - проверка и исправление кода
- `npm run format` - форматирование кода

## 🎨 Кастомная конфигурация Tailwind

Проект использует `@tailwindcss/vite` и расширенную конфигурацию с кастомными цветами, breakpoints и shadows:

```css
--breakpoint-ss: 420px;
--breakpoint-ml: 920px;
--color-blue-500: #337566;
--color-negative-500: #bd3223;
--shadow-2md: 0 4px 10px 0 rgba(16, 21, 52, 0.1);
```

## 📱 Адаптивность

Проект полностью адаптивен и использует breakpoints:

- **ss** (420px) - малые экраны
- **ml** (920px) - средне-большие экраны
- Стандартные Tailwind breakpoints

## ⚠️ Важно

Убедитесь, что имена компонентов не конфликтуют с зарезервированными HTML элементами. Например, компонент должен быть `AppHeader`, а не `Header`.
